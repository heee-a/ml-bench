# 项目三 · 世界发展指标：中国 20 余年变迁与 Preston 曲线

用世界银行官方 API 采集 217 个国家/地区 2000-2023 年的四项核心发展指标
（共 20,330 行面板数据），回答：中国的变化有多快？收入和寿命的关系多强？

![中国2000-2023](charts/china_2000_2023.png)

## 数据来源与采集

| 项 | 说明 |
|---|---|
| 数据源 | [World Bank API v2](https://datahelpdesk.worldbank.org/knowledgebase/topics/125589)（公开免费） |
| 指标 | 人均GDP、预期寿命、人均CO2、城市化率 |
| 采集方式 | `collect.py`：单指标全量请求（4 次）+ 国家元数据剔除聚合区（欧盟/世界等非国家条目） |
| 采集实战 | 旧 CO2 指标码 `EN.ATM.CO2E.PC` 已被世界银行归档，按错误信息换用新码 `EN.GHG.CO2.PC.CE.AR5` |

## 清洗与口径

- 宽长转换：长表 → 以 (国家, 年份) 为索引的四指标宽表；
- 缺失值按指标自然存在（小国部分年份缺 CO2），分析时按需 dropna 不做插补；
- 排名基于 2023 年有值的 204 个国家。

## 核心发现

1. **中国 23 年人均GDP 13.4 倍**：969 → 12,951 美元；城市化率 36% → 66%，
   预期寿命 72.3 → 78.0 岁——三条曲线同步陡升；
2. **位置感**：2023 年中国人均GDP 全球 84/204，但仍只有全球中位数（7,862 美元）的
   1.6 倍、约为美国的 15%——"总量大、人均中"的格局没有变；
3. **Preston 曲线**：收入与预期寿命 Spearman 相关 **0.86**（Pearson 仅 0.62，
   收入右偏拉低了线性相关——这就是要取对数的原因）；
4. **人均CO2**：中国 9.2 吨 vs 美国 13.7 吨（美国 1.5 倍），总量与人均是两回事；
5. 中国城市化率已略高于全球中位数（+1.9pp），但仍低于发达国家 80%+ 的水平。
