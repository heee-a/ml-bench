# 检索方法对照：BM25 vs TF-IDF+SVD(LSA) vs 混合

用同一套语料（本账号作品集 13 篇 README，81 个分块）和同一套评测集
（12 个中文问题），公平对比三种检索方法。结论可能反直觉，但数据如此：

| 方法 | recall@3 | MRR |
|---|---|---|
| **BM25** | **83%** | **0.750** |
| TF-IDF + SVD (LSA) | 67% | 0.514 |
| Hybrid（两者分数归一化 0.5/0.5） | 75% | 0.694 |

## 为什么 BM25 赢了"更高级"的 LSA

- **语料太小**：81 个块、13 篇文档，LSA 的语义空间没有足够共现统计来学出
  稳定的潜在主题；短查询在 48 维空间里区分度反而下降；
- **词面匹配在这个任务里就是对的**：评测问题多为关键词精确匹配
  （"LRU 缓存"、"LAG"、"爬虫"），BM25 的词频/IDF 信号直接有效；
- **混合不是免费午餐**：归一化混合把 BM25 的精确度稀释掉了。

**启示**：做检索系统不要默认"向量检索 > 关键词检索"，先建评测集、
跑基线、用数字说话——这正是本项目的流程。语料规模上去、引入查询改写
或真正的 embedding 模型后，结论可能反转（但那需要评测来证明）。

## 实现

- TF-IDF：`TfidfVectorizer(tokenizer=jieba 分词)`；LSA：`TruncatedSVD(48)` +
  L2 归一化，查询投影同空间取余弦；
- 评测协议与 ai-lab RAG 项目一致（12 问，命中=目标文档+关键词同时满足）。

## 复现

```bash
python run_search_bench.py
```
