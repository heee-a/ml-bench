# 项目五 · 统计推断实战：三个带完整流程的假设检验

用项目一的气象数据做正式的假设检验——重点不是"算 p 值"，而是展示完整流程：
**H0/H1 定义 → 检验方法选择理由 → 统计量/p 值 → 效应量 → 置信区间 → 结论与局限**。

## 三个检验与结果

### 检验一：北方城市夏季降水占比更高？（直觉不总成立）
- 分组：秦岭-淮河 33°N，北方 n=7、南方 n=11（样本单位是城市，不是天——避免伪重复）
- Welch t：t=0.97, p=0.36；Mann-Whitney U：p=0.21；Cohen's d=0.55（中效应）
- 均值差 95% Bootstrap CI：[-5.6, +16.4]pp，跨 0
- **结论：不能拒绝 H0。** "北方雨季更集中"的直觉在这 18 城样本上不成立——
  负结果也值得报告，效应量为中但样本小导致功效不足是合理的解释方向。

### 检验二：沿海城市年降水量更高？（显著，大效应）
- 沿海 n=5 vs 内陆 n=13：748mm vs 460mm
- Welch t：p=0.011；Mann-Whitney：p=0.007；**d=1.56（大效应）**
- 均值差 CI：[+132, +446]mm，远离 0 → **拒绝 H0**

### 检验三：昆明"四季如春"（统计上成立）
- Levene 方差齐性检验：昆明月均温标准差 4.3℃ vs 其他城市 10.7℃，W=7.18, p=0.008
- **拒绝 H0：昆明的月度气温波动显著更小**——用统计语言验证了一句俗语。

## 方法论说明（面试高频追问点）

- **为什么同时报 t 检验和 Mann-Whitney？** n<10/组时正态性不可靠，以对分布
  假设更宽松的 Mann-Whitney 为结论依据，t 检验作为参考；两者结论一致时更稳健。
- **为什么用 Bootstrap CI？** 小样本下均值差的解析置信区间依赖正态假设，
  Bootstrap（10,000 次重抽样）更稳。
- **效应量不能省**：p 值只回答"有没有差异"，Cohen's d 回答"差多大"——
  检验一 p=0.36 但 d=0.55，提示增大样本后可能显著；
- **多重比较**：三个检验构成族，严格做法是 Bonferroni 校正（α=0.05/3≈0.017），
  校正后检验二、三仍显著，检验一仍不显著——结论不变；
- **局限**：18 个城市是便利样本；"沿海/南方"分组依据地理常识，非随机分组，
  因果语言（"导致"）一律不使用。
