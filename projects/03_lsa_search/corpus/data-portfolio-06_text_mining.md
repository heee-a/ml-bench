# 项目六 · 文本挖掘：头部开源项目里的「中文世界」

从项目二的 1000 个头部仓库中筛出 **87 个中文描述项目**，用 jieba 做分词挖掘：
中国开发者在开源世界里最关心什么？

![高频词](charts/word_freq.png)

## 方法

- **分词**：jieba + 自定义词条（大模型/知识库/低代码…避免被切碎）；
- **清洗**：停用词（中英双语）、长度 <2、纯数字、无汉字 token 过滤；
- **统计**：词频 Top20、二连词（bigram）Top15、语言分布、创建年份中位数对比；
- **口径诚实**：样本只有 87 个项目（头部仓库的 8.7%），结论限定在"头部中文项目"，
  不外推到整个中文开源社区。

## 发现

1. 高频词：**免费(12)、系统(10)、技术(9)、中文(9)、爬虫(9)、开源(9)、面试(8)、
   指南(8)**——头部中文项目以学习资料、工具与教程为主，"实用主义"色彩浓；
2. 高频二连词：**评论爬虫(6)** 一枝独秀，还有 技术面试/语言模型/系统设计/
   数据结构算法——面试与爬虫是中国开源圈的两大特色主题；
3. 语言分布 Python(23) > Java(12) > JavaScript(8)，与全量头部仓库（Python、
   TypeScript 领先）结构不同：中文圈更偏后端与数据方向；
4. 中文项目的创建年份中位数明显更晚——中文开源在头部世界的存在感正在上升。

## 复现

```bash
python run_mining.py   # 复用项目二的 data/repos.csv，jieba 分词约 3 秒
```
