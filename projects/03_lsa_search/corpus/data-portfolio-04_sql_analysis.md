# 项目四 · 用 SQL 看世界发展数据（10 个业务问题）

把项目三采集的世界发展指标导入 SQLite（一张事实表 + 一张国家维表），
用 **10 个纯 SQL 查询**回答业务问题——所有查询都是手写 `.sql` 文件，
覆盖 JOIN、窗口函数、CTE、条件聚合、多层子查询。

## 技术要点

| SQL 技能 | 对应问题 |
|---|---|
| 窗口函数 LAG | Q2 中国人均GDP 同比增速 |
| 窗口函数 ROW_NUMBER/RANK + PARTITION | Q5 每年GDP冠军、Q9 中美 CO2 排名变化 |
| CTE 多层拆解 | Q2/Q5/Q8/Q9 |
| 条件聚合（CASE 透视） | Q4 地区城市化对比、Q6 中印倍数 |
| 自连接 + 阈值分层 | Q8 收入等级跃迁 |
| 多条件业务筛选 | Q10 高收入且低碳国家 |

## 三个值得在面试里展开的结果

1. **Q8 跨越中等收入陷阱有多难**：2000→2023 年仅 19 个国家从非高收入跃迁为
   高收入（16 个从上中收入：波兰/智利/克罗地亚…；3 个从下中收入：保加利亚/
   罗马尼亚/圭亚那），没有一个人口过亿的发展中大国在列——且名义门槛还在逐年抬高；
2. **Q5 人均口径的"冠军"全是小国**：卢森堡/摩纳哥长期霸榜，说明人均指标必须
   结合人口规模解读（面试常考的口径陷阱）；
3. **Q2 中国 2001-2011 年增速全部两位数**（窗口函数算出的 YoY），
   2015 年后回落到个位数——数据里的经济周期。

## 复现

```bash
python build_db.py     # 读取项目三的数据 -> data/world.db（事实表+维表+索引）
python run_queries.py  # 执行 sql/*.sql -> report.md（SQL 原文+结果表+解读）
```

完整查询与结果见 [report.md](report.md)，SQL 文件在 [sql/](sql/) 目录。
数据口径：名义美元；Q8 按世界银行当年名义门槛分层（2000：≥9266，2023：≥14005）。
