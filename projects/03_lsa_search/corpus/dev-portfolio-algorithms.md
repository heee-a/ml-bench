# 算法专题：手写实现 + 复杂度注释 + 参数化测试 + 性能基准

不刷题网站的题解搬运，而是把**面试高频的 25+ 个经典算法**按专题重新实现一遍：
每个都有中文注释讲清「思路 → 复杂度 → 面试追问点」，每个都有与内置标准实现
对照的参数化测试，排序系列还有实测性能基准。

## 专题地图

| 模块 | 内容 | 高频面试点 |
|---|---|---|
| [sorting.py](sorting.py) | 冒泡/插入/选择/归并/快排/堆排 | 稳定性、快排最坏退化场景、建堆 O(n) |
| [searching.py](searching.py) | 二分及左右边界、旋转数组、峰值查找 | 边界写不死循环的技巧、`right-left` 数出现次数 |
| [dynamic_programming.py](dynamic_programming.py) | 斐波那契/爬楼梯/LIS/LCS/编辑距离/0-1背包/零钱/回文子序列 | 滚动数组、遍历顺序决定背包类型、DP 三级优化 |
| [graph.py](graph.py) | BFS/DFS/无权最短路/拓扑排序/Dijkstra/并查集 | BFS 首达即最短、Dijkstra 负权失效、路径压缩 |
| [strings.py](strings.py) | KMP/最长回文/无重复最长子串/异位词分组 | 前缀函数含义、滑动窗口模板 |
| [data_structures.py](data_structures.py) | 反转链表/判环/中点、最小栈、LRU、Trie | 快慢指针、辅助栈同步、双向链表+哈希 |

## 性能基准（实跑数据）

```
算法         n=200 (s)    n=2000 (s)    n=8000 (s)
bubble         0.0010        0.1054        1.7292
insertion      0.0003        0.0405        0.6721
selection      0.0007        0.0686        1.1639
merge          0.0002        0.0026        0.0125
quick          0.0002        0.0022        0.0101
heap           0.0002        0.0022        0.0109
```

n=8000 时 O(n²) 与 O(n log n) 相差百倍以上——复杂度理论在真实机器上完全可复现。
重跑：`python benchmark.py`

## 测试

```bash
pytest tests/test_algorithms.py -q     # 25 项正确性测试（与 sorted()/标准实现对照）
```

设计说明：排序测试用参数化覆盖 8 种边界输入（空/单元素/全相同/逆序/已排序/负数）；
图测试断言遍历集合而非顺序（DFS 依邻接表顺序不唯一）；拓扑排序对有环输入断言
返回空——这正是 Kahn 算法做环检测的原理。
