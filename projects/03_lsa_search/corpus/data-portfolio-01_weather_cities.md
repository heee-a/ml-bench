# 项目一 · 全国主要城市气象数据分析

对 18 个主要城市 2019-2024 年共 **39,456 天**的逐日气象数据做了一次横纵交叉分析：
南北气候差异到底有多大？降水有多集中？哪些城市"四季如春"？

![月均温曲线](charts/monthly_temp.png)

## 数据来源与采集

| 项 | 说明 |
|---|---|
| 数据源 | [Open-Meteo Archive API](https://open-meteo.com/en/docs/historical-weather-api)（免费、无 Key、可商用） |
| 范围 | 18 城 × 2019-01-01 ~ 2024-12-31 逐日：最高/平均/最低气温、降水量 |
| 采集方式 | `collect.py`，每城一次请求共 18 次；磁盘缓存 + 3s 限速 + 429 自动退避 61s |
| 采集实战 | 共享出口 IP 触发过一次每分钟限流，退避后自动恢复——礼貌限速不是摆设 |

## 清洗与口径

- 长表存储（city × date），实测缺失率 **0%**（ERA5 再分析数据，无站点缺测问题）；
- "最冷月/最热月均温"按城市 × 月份聚合后再取 min/max，避免单日极值的噪声；
- "升温速率"为年均温对年份的线性拟合斜率。**6 年太短，不代表气候结论**，
  图表标题中已注明，防止误读（这也是一种数据素养）。

## 核心发现

1. **年均温跨度 20.2℃**：最高三亚 25.9℃，最低哈尔滨 5.7℃；
2. **中国气候"冬差远大于夏差"**：最热月均温全国范围仅 16.7~30.0℃（差 13.3℃，武汉
   30.0℃ 最热），而最冷月 -16.0℃（哈尔滨）~21.4℃（三亚）差 37.4℃——
   所以全国夏天一起热、冬天各自冷；
3. **降水极度集中**：广州 2252mm/年 是乌鲁木齐 225mm 的 **10 倍**；北京夏季降水占
   全年 **71%**，典型的季风气候；
4. **"四季如春"量化**：温度年较差昆明 11.7℃（冬 9.0℃/夏 20.7℃，真正四季如春），
   哈尔滨 39.9℃ 最极端；年较差与纬度线性强相关（纬度 +1° ≈ 年较差 +1.4℃）；
5. 样本期内成都/重庆升温速率最高（≈0.28℃/年），但 6 年样本不足以支撑气候结论。
